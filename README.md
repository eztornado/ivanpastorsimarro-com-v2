# ivanpastorsimarro-com-v2

---

## 🇬🇧 English

### About

This is the personal portfolio website of **Iván Pastor Simarro**, a technical leader specialist / software developer with a backend profile. The site showcases his projects, technical skills, social links, and contact information.

### Features

- **Trilingual support**: English, Spanish, and Japanese (with automatic language detection).
- **Responsive design**: Optimized for desktop and mobile devices.
- **Dark/Light mode**: Toggle between color schemes.
- **Smooth navigation**: Anchor-based scrolling with a sticky navbar.

### Tech Stack

| Category | Technology |
|---|---|
| **Frontend** | React 19, TypeScript |
| **UI Framework** | Mantine v8 |
| **Icons** | Tabler Icons |
| **Routing** | React Router v7 |
| **Internationalization** | i18next + react-i18next + i18next-browser-languagedetector |
| **Build Tool** | Vite v7 |

### Getting Started

**Prerequisites:** Node.js 18+ and npm.

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
